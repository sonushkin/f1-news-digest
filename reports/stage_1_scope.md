# Stage 1 Checkpoint

- Everyday task selected: checking and updating Formula 1 news.
- Project working title: **F1 News Digest**.
- Interface: Python console application.
- Minimum scope: one verified public RSS or Atom source, configurable item
  limit, optional keyword filter, formatted digest, and local new/seen history.
- Local persistence: JSON history stored within the project.
- Testing boundary: parsing and core logic must be testable with a local feed
  fixture; live network access is not treated as the only test.
- Out of scope: full-article scraping, AI paraphrasing, accounts, secrets,
  notifications, GUI, and multi-source aggregation.

**Checkpoint result:** Stage 1 scope is complete and ready for learner review.
No application code or Git repository has been created yet.
